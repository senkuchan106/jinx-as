# JINX AS Website

Plain HTML/CSS/JavaScript website for JINX AS.

Includes the supplied Jinx artwork, the JINX AS description, full LT2/HT3/LT3 rosters, Minecraft and FPS links, a Create section, permanent Discord invite, no application form, responsive navigation, animations, and the footer credit "Website made by Senku".

Edit `index.html` for text and links, `styles.css` for the design, and `script.js` for the roster.


CURSOR SETUP
The custom cursor files MUST stay beside index.html: jinx-cursor.png and jinx-pointer.png. Do not move them into assets/. Open index.html after extracting the complete folder.
